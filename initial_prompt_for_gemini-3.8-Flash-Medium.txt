A qt quick application written in modern c++20 using qt 6.8.3 compiled to webassembly (single-thread) and hosted on GitHub Pages. 

For now this is a Web-App, with focus on Mobile, but also compiled for Desktop for testing during development. This application will also be included in an Android app, later.

All computation and storage of user data is done locally, no online-only and no phoning-home or such behavior. We avoid collecting any user data, the user is responsible for their own data. We do not collect any user data. The user can save the Settings and pantry which is done in the browser or on Desktop via QSettings.
if the user decides to connect their pantry with another user's pantry, this is possible via Cloudflare durable objects. The user has to create his own instance of a Cloudflare durable object according to the instructions we provide and set the Connection Details in the Settings screen, to allow sharing a pantry/Shopping list.

The application contains of the following screens:
- the pantry (what the user has. it is the list of all ingredients from all recipies and the user can select if the ingredient is available)
- the Shopping list (what the user does not have. this is the list of all ingredients that are not in the pantry. the shopping list can be sorted and filtered by ingredients that are used in starred recipies)
- the recipies (this is the list of all recipies. a recipie has a title and a list of ingredients with amounts.) sortable and filterable by the suggestion System. by Default Shows only recipies for which all ingredients are available and that are suitable for the current time of day. the user can star recipies.
- the Settings (here the user can edit the categories of the recipes and the preferred time Slots for the categories)
- the selected recipie (this is the screen that Shows the full recipy including all ingredients, amounts. it allows changing serving size and the application displays the the recalculated amounts of ingredients for that serving size. Here the formatted preparation instructions are shown from the markdown preparation instructions, which are not provided yet.)

Other modules of the application:
- the suggestion System (this checks which recipies can be made with the available ingredients from the pantry. This module also take into Account the preferred time for meals (e.g. breakfast 04:00-08:00, morning Snack 09:00-12:00, lunch 11:00-14:00, afternoon Snack 13:00-16:00, evening Snack 15:00-19:00, dinner 17:00-21:00, etc.). the suggestion System is used in the recipies screen for sorting and filtering the recipies.
- the recipie Collection (we might add the possibility to add or Change recipies in the future, or allow connecting to a global recipy Cloudflare durable object which allows adding recipies from the global Collection to the private offline Collection of recipies)

Recipies do not have instructions for preparation, yet. We might add this in the future, for now this is empty. I would like to allow markdown Format for the preparation instructions which can be rendered in qt quick text/labels Pretty nicely.
The recipies shall be added as a json file to the repository. The json is also included as a resource in the application, and imported on first run to the user Settings. On user request, the recipies list can be refreshed from the website mesw.github.io/Malzeit/res/recipies.json. This allows making changes to the Default recipies later without recompiling the webassembly.

the desired repository structure:
source/ # all the code files
resources/ # recipie json and any images
build/ # this is the build Folder from qt creator. there is the webassembly build Folder inside, from which we will deploy the relevant files directly. if there is a better way than storing These build artifacts in for deployment on GitHub pages in the git source tree, then let me know!
index.html # the GitHub pages index. this contains a short info page about the project including a link to the repo, the 3 sentence privacy policy and a "agree and launch" button that Forwards to the build/WebAssembly_Qt_6_8_3_single_threaded-Release/index.html
